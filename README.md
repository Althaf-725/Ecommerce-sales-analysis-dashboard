# Ecommerce-sales-analysis-dashboard
"Built an end-to-end retail analytics dashboard using a simulated e-commerce dataset to analyze sales performance, customer behavior, and discount trends."

## Project Overview

This project analyzes e-commerce sales data using Power BI to uncover insights into sales performance, customer behavior, discount impact, and payment trends.

## Dataset

- 21,500 transaction records
- 12 attributes
- Categories: Men, Women, Kids, Beauty, Home & Living

## Tools Used

- Power BI
- DAX
- CSV
- Data Modeling

## Key KPIs

- Total Sales: 9.26M
- Total Quantity Sold: 4463
- Total Discount: 36K
- Unit Price Analysis

## Dashboard Pages

### Executive Summary
- KPI Cards
- Category Filters
- High-level Overview

### Sales Analysis
- Sales by Category
- Sales by Brand
- Sales Trends

### Customer Insights
- Gender Analysis
- Regional Distribution

### Payment & Pricing
- Payment Mode Distribution
- Discount Analysis

## Business Insights

- Home & Living generated the highest sales.
- Biba and W brands contributed significantly to revenue.
- Male and Female customer sales were nearly equal.
- Net Banking and UPI were popular payment methods.
